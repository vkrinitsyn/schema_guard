# schema_guard_tokio 2.4.0

2026-11-19.

## New

- **A database each, by feature.** `postgres` is the default and gives what 2.x gave. `mysql`
  brings MySQL through sqlx (`mysql::{migrate, plan, load_info_schema}`), `sqlite` an embedded
  SQLite through turso (`sqlite::{migrate, plan, load_info_schema}`). With no feature the crate
  still parses, validates and maps a YAML; nothing connects.
- **A schema moves between databases.** A schema's top-level `source: vendor.version` says what
  wrote it, and the type mappings carry it each way between PostgreSQL, MySQL and SQLite; a
  literal default goes through the rules too (a boolean's 0 and 1 to false and true).

## Changed

- With `default-features = false`, name `postgres` to keep it.

## Fixed

- `bpchar(n)` is read with its length; a `char` with no length compares as one.
